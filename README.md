## 🚀 Overview

**AI Docs Assistant** is a modern, full-stack application built to bridge the gap between users and complex, dense documentation. Whether you are dealing with technical manuals, legal files, or entire books, this platform leverages advanced AI and semantic vector search to unlock your content instantly.

Engineered with modern frontend and backend standards, it showcases a responsive user experience, lightning-fast search capabilities, interactive AI chat interfaces, and a scalable architecture.

---

## ✨ Core Features

*   💬 **Interactive AI Chat:** Engage in conversational queries directly with your documents for precise, context-aware answers.
*   ❓ **Automated Question Generation:** Instantly generate review or study questions based on specific documentation sections.
*   📑 **Chapter-by-Chapter Summaries:** Automatically parse and summarize long documents or books chapter by chapter to save hours of reading.
*   ⚡ **Lightning-Fast Semantic Search:** Find exact references across massive knowledge bases using high-performance vector retrieval.
*   🎨 **Modern Responsive UI:** Clean, accessible interface built with Tailwind CSS and modern component libraries.
*   📐 **Engineered with Precision:** Built using **Spec-Driven Development (OpenSpec)** and advanced AI-assisted engineering workflows.

## 🛠️ Local Development

### Prerequisites
- Node.js version 18.x or higher
- Python 3.10+ (if running local backend scripts/embeddings)
- `npm`, `yarn`, or `pnpm`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/amxnos20/ai-docs-assistant.git
   cd ai-docs-assistant
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Configure environment variables:** Duplicate the example file and add your credentials:
   ```bash
   cp .env.example .env.local
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
Open http://localhost:3000 in your browser to view the application.
