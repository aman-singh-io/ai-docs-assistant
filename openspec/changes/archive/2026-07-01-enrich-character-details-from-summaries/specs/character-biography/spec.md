## MODIFIED Requirements

### Requirement: Character biography includes Portrait section when appearance data exists
The character biography (wiki-style profile) generated by the system SHALL include a **Portrait** section describing the character's physical appearance, clothing, and notable possessions when `characterDetails` data is available across relevant chapters.

#### Scenario: Biography generated with appearance data
- **WHEN** a user requests a character biography and at least one relevant chapter contains `characterDetails` for that character
- **THEN** the biography SHALL include a Portrait section covering physical appearance, clothing, and notable items

#### Scenario: Biography generated without appearance data
- **WHEN** a user requests a character biography and no relevant chapter contains `characterDetails` for that character
- **THEN** the biography SHALL NOT include an empty or placeholder Portrait section

#### Scenario: Portrait aggregates across chapters
- **WHEN** character details appear across multiple chapters (e.g., a scar mentioned in ch.1, a sword in ch.3)
- **THEN** the Portrait section SHALL synthesise all known details into a coherent description rather than listing them chapter by chapter
